# NS GLASS — Ultra-Premium Architectural Glass Website Theme

An ultra-premium, mobile-first architectural glass engineering and commercial studio website theme developed for **NS GLASS** (Bapatla, Andhra Pradesh), founded by **Burla Narendra**.

Designed with a luminous light frosted glassmorphism visual aesthetic, responsive fluid typography, and an interactive 3D WebGL product configurator with real-time price estimation.

---

## 💎 Design System & Visual Identity
- **Canvas Aesthetic**: Luminous ice/sky-blue atmospheric canvas (`#eaf2fb` &rarr; `#f4f8fd` &rarr; `#dcebfc`) with multi-layered ambient radial refractive glows.
- **Translucent Frosted Glassmorphism**: High-performance multi-layer backdrops (`backdrop-filter: blur(20px)`), crisp 1px borders, subtle inset light reflections, and soft blue drop shadows.
- **Royal Blue Gradient CTAs**: Vivid gradient pills (`#0066ff` &rarr; `#0052cc`) with tactile mobile active-state scaling.
- **Fluid Typography**: Responsive CSS `clamp()` typography smoothly scaling from mobile viewports (360px – 480px) to ultra-wide desktop screens (2560px+).

## 🚀 Key Pages & Features

1. **Home (`index.html`)**:
   - Hero section with interactive slide carousel, glass badges, and dual primary/secondary action CTAs.
   - Quick stats strip with region metrics (500+ Projects, 10+ Years Excellence, Bapatla coastal focus).
   - Interactive Before/After restoration slider with touch/mouse scrub.
   - Core solutions showcase and Meet Founder (**Burla Narendra**) feature card.

2. **Interactive 3D Studio & Estimator (`3d-view.html`)**:
   - Real-time Three.js WebGL 3D shower enclosure visualization.
   - 360° orbit view, angle presets (Front, Angle, Inside), and fullscreen toggle.
   - Glass swatch selector (Clear, Frosted, Laminated, Toughened).
   - Real-time dimension controls and instant price estimation engine.
   - AR space-preview modal with QR code launcher.

3. **Product Collections (`types.html`)**:
   - Frameless Shower Cubicles, Acoustic Office Partitions, SS-316 Balcony Railings, Decorative Stained Glass, and Spider Glazing.
   - Comprehensive glass specification tags (Thickness, ISI Mark, Hardware Grade).

4. **Safety & ISI Standards (`safety.html`)**:
   - IS 2553 Part 1 certified architectural safety guide.
   - Thermal shock resistance (250°C), SS-316 coastal marine-grade hardware specs.
   - Shatter comparison table and interactive thickness selector.

5. **Founder & Studio Heritage (`profile.html`)**:
   - Founder biography of **Burla Narendra**, Principal Director of NS GLASS.
   - Coastal durability engineering manifesto (saline humidity protection, wind load calculations).
   - Core pillars: Zero-Defect Saint-Gobain/AIS Glass, Marine-Grade SS-316, Millimeter Laser Fitting.

6. **Project Gallery (`gallery.html`)**:
   - Filterable project grid (Shower Enclosures, Office Partitions, Decorative Glass, Residential, Commercial).
   - Interactive Before / After showcase and image expander modal.

7. **Contact & Site Visit Booking (`contact.html`)**:
   - Multi-tab engagement panel: Send Inquiry, Book Site Visit, Quick WhatsApp Quote.
   - Studio address in Bapatla with direct click-to-call, WhatsApp, and Google Maps routing.

8. **Universal Floating Consultation Widget**:
   - Founder avatar with live online status badge.
   - Quick WhatsApp launch and site visit booking triggers across all pages.
   - Mobile-optimized collapse and floating reopen pill.

## 📱 Mobile Responsiveness & Scaling
- Zero horizontal layout overflow across all viewports (tested explicitly at 360px, 375px, 390px, 412px, 480px, 768px, 1024px, 1440px, and 1600px).
- Minimum 44px &times; 44px touch targets on all buttons, links, dimension steppers, and menu controls.
- 16px form field base font size to eliminate iOS Safari auto-zoom on input focus.
- Safe-area bottom padding ensuring floating consultation controls never obscure content.
